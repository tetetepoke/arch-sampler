# テスト対策ドリル（中学生向け 総合テスト対策アプリ）

公開URL: https://tetetepoke.github.io/arch-sampler/study/

iPhone向けの定期テスト対策アプリ。教科 → 分野 → 単元（→ 小単元）を選び、
テスト直前／10問・20問チャレンジ／全問題／ランダム／苦手問題だけ で出題する。
記録は端末のブラウザ（localStorage `teststudy.v2`）に保存。サーバーは使わない。

---

## ファイル構成

```
study/
├─ index.html          画面の土台（ふだん触らない）
├─ style.css           デザイン（ふだん触らない）
├─ app.js              アプリ本体（問題追加では触らない）
├─ data/
│  ├─ registry.js      問題の登録口（触らない）
│  ├─ catalog.js       教科・分野・単元の一覧と表示順、IDのコード表
│  ├─ manifest.js      読み込む問題ファイルの一覧  ← 新しいファイルを作ったら1行足す
│  └─ questions/
│     ├─ shakai/       社会   soc-*.js
│     ├─ sugaku/       数学   math-*.js
│     ├─ eigo/         英語   eng-*.js
│     ├─ rika/         理科   sci-*.js
│     └─ kokugo/       国語   jpn-*.js
└─ tools/check.js      問題データのチェック（重複・形式・次のID）
```

**問題を増やすときに編集するのは `data/questions/` のファイルと `data/manifest.js`（新ファイルのときだけ）。**
単元が `catalog.js` に無くても動く（その分野の最後に自動で出る）が、表示順やIDコードを決めたいときは `catalog.js` にも足す。

## 問題を追加する手順（Claude向け・この順番で行う）

1. **既存の問題を確認する**：対象単元のファイルを読み、同じ内容の問題を作らない。
2. **次のIDを調べる**：`node study/tools/check.js --next`
3. **問題を書く**
   - 既存の単元 → そのファイルの配列の末尾に追記（IDは連番で続ける）
   - 新しい単元 → `data/questions/<教科フォルダ>/` に新しいファイルを作り、`data/manifest.js` に1行足す
4. **チェックする**：`node study/tools/check.js`
   - 「エラーなし」になるまで直す
   - 「似ている問題」の警告が出たら、本当に別の問題か確認する（同じなら削除・書き換え）
   - 難易度の割合（★ 約50%・★★ 約35%・★★★ 約15%）も表示されるので、かたよりがあれば調整する
5. **コミットして main に push**（GitHub Pages に数分で反映）

1ファイルは1単元（小単元）にする。1ファイルあたり300問程度までを目安に、多くなったら `soc-geo-asia-southeast-2.js` のように分ける。

## 問題ファイルの書き方

```js
/* 理科 › 生物 › 植物のつくりとはたらき */
StudyData.add(
  { subject: "理科", category: "生物", unit: "植物のつくりとはたらき", grade: 1 },   // ← ファイル内の共通項目
  [
    { id: "SCI-BIO-PLANT-001", type: "choice", difficulty: 1, importance: 3,
      question: "花のつくりで、受粉後に種子になる部分は？",
      choices: ["胚珠", "子房", "やく", "柱頭"],
      answer: "胚珠",
      explanation: "胚珠は子房の中にあり、受粉すると種子になる。子房は果実になる。",
      tags: ["花のつくり"] },

    { id: "SCI-BIO-PLANT-002", type: "tf", difficulty: 1, importance: 2,
      question: "被子植物では、胚珠が子房に包まれている。",
      answer: true,
      explanation: "○。子房に包まれているのが被子植物、むき出しなのが裸子植物。" }
  ]
);
```

共通項目を書かずに、1問ずつ全部書いてもよい（どちらでも同じように動く）：

```js
StudyData.add([
  { id: "SOC-GEO-SEA-079", subject: "社会", category: "地理", unit: "東南アジア", grade: 1,
    type: "choice", question: "…", choices: [...], answer: "…", explanation: "…", difficulty: 1, importance: 2 }
]);
```

### 項目一覧

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | ○ | 一意のID。`教科-分野-単元-連番3桁`（例 `SOC-GEO-SEA-001`）。コードは `catalog.js` の `code` |
| `subject` | ○ | 教科：社会 / 数学 / 英語 / 理科 / 国語 |
| `category` | ○ | 分野：地理・歴史・公民、数と式・関数・図形、文法、生物・化学…（`catalog.js` 参照） |
| `unit` | ○ | 単元。小単元がある場合は **いちばん細かい名前**（例：アジア州ではなく「東南アジア」） |
| `grade` | | 学年 1 / 2 / 3（省略時 1） |
| `type` | | 問題形式（下表）。省略時 `choice` |
| `question` | ○ | 問題文。穴埋めは空欄を `（　　　）` で書く |
| `choices` | 4択は○ | 選択肢（4つ）。表示時にシャッフルされる |
| `answer` | ○ | 正解（下表） |
| `accept` | | 記入式の別解の配列（例 `["季節風", "モンスーン"]`）。ひらがな/カタカナ・全角/半角・空白・かっこの違いは自動で同じ扱い |
| `keywords` | | 記述問題のキーワード。`"高温|気温が高い|暑い"` のように `|` で言い換えを並べる |
| `explanation` | ○ | 解説。答えだけでなく「なぜそうなるか」を中学生に分かる言葉で1〜3文 |
| `difficulty` | | 難易度 1=★基本 / 2=★★標準 / 3=★★★応用（省略時 1） |
| `importance` | | 重要度 1=低 / 2=普通 / 3=**テスト頻出**（省略時 2）。テスト直前モードで3を優先 |
| `tags` | | キーワードの配列（任意） |
| `variantOf` | | わざと同じ内容を別形式で出す場合、元の問題ID（重複チェックで警告にしない） |
| `image` | | 地図や図を表示する場合の画像パス（study/ からの相対パス。例 `images/asia/map-blank.svg`）。問題文の下に表示される |
| `imageAlt` | | 画像の説明文（読み上げ用） |

### 地図問題を作るとき
- 画像は `study/images/<単元>/` に置き、`image: "images/asia/map-blank.svg"` のように指定する（SVG推奨、PNG/JPGも可）。
- 画像に「A〜D」の記号を書いておき、`choices: ["A", "B", "C", "D"]` で答えさせると作りやすい。
- 画像がない位置問題は `tags` に `"地図"` を付けておく（あとで画像を足すときに探しやすい）。
- `tools/check.js` が画像ファイルの存在もチェックする。

### 問題形式（type を変えるだけで表示が切り替わる）

| type | 表示 | answer |
|---|---|---|
| `choice` | 4択ボタン | 正解の選択肢の文字列 |
| `tf` | ○×の大きなボタン | `true`（○）/ `false`（×） |
| `fill` | 穴埋め。`choices` があれば選択式、なければ文字入力 | 正解の文字列（＋`accept`で別解） |
| `written` | 記述。書いたあと模範解答とキーワードを表示し、自分で「できた／まちがい」を判定 | 模範解答の文 |

## 出題・記録のしくみ（app.js）

- **苦手度**：1回間違い＝要復習、2回＝苦手、3回以上＝最重要復習。2回続けて正解すると1段階下がり、0になると克服。
- **テスト直前**：苦手度・正答率の低さ・`importance` を点数にして、高いものほど出やすい15問。
- **10問／20問チャレンジ**：ランダム（まだ解いていない問題と苦手を少し優先）。
- **全問題**：ファイルの順番どおり。**ランダム**：全問をシャッフル。**苦手問題だけ**：苦手度が高い順。
- 難易度（★/★★/★★★）で絞り込める。学年（中1/中2/中3/全学年）はホームで切り替え。
- 旧バージョン（`teststudy.v1`）の記録は、初回起動時に新しいIDへ自動で引き継ぐ。

## IDのコード（主なもの。全部は catalog.js）

教科：SOC 社会 / MATH 数学 / ENG 英語 / SCI 理科 / JPN 国語
社会の分野：GEO 地理 / HIS 歴史 / CIV 公民
アジア州：ASIA 総合 / EA 東アジア / SEA 東南アジア / SA 南アジア / WA 西アジア / CA 中央アジア
（記録が問題IDにひもづいているため、既存IDのコードは変えない。EAS・SAS などの別名は使わない）
新しい単元のコードは英大文字で短く決めて、`catalog.js` にも書く。
